# KBP AI brand assets

The Owner adopted the typographic identity on October 10, 2026: bold KBP, thin AI, one full name on one line. Knowledge Becomes Progress is the primary slogan.

Use [identity-v1](identity-v1) for new placements. The [identity standard](../docs/IDENTITY.md) specifies master geometry, avatar cropping, themes, minimum sizes and disclosure. The older wordmark-light.jpg remains historical; it is not the source for new exports.

- Wordmark SVG: [light](identity-v1/kbp-ai-wordmark-light.svg), [dark](identity-v1/kbp-ai-wordmark-dark.svg), [currentColor](identity-v1/kbp-ai-wordmark-currentcolor.svg).
- Square avatar PNG, 1024px: [dark](identity-v1/kbp-ai-avatar-dark-1024.png), [light](identity-v1/kbp-ai-avatar-light-1024.png).
- Large signature with slogan: [dark](identity-v1/kbp-ai-signature-dark.svg), [light](identity-v1/kbp-ai-signature-light.svg).
- [Social link card](identity-v1/kbp-ai-social-card.jpg), 1200 × 630.

Logo letters are vector paths. The companion slogan is outlined DejaVu Sans; its [license](identity-v1/DEJAVU-LICENSE.txt) is included. Do not replace the logo with an isolated K or an unrelated icon. The prototype status on the link card is intentional. A file in this repository does not establish that website metadata or account profile photos have been updated.
