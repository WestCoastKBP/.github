# What we're building

KBP AI is an AI work environment we build and test on our own daily tasks. There is no public application release yet.

## Two directions

**Tools for building software with agents.** Our development work uses agents from more than one vendor. We are working on how tasks receive context, how agents use tools and hand work over, and how changes are reviewed and their results checked. Useful parts of this workflow are candidates for an open-source release.

**Practical assistants and integrations for business workflows.** We use correspondence and business tasks to explore where an assistant helps and where a person needs to decide. Current work includes incoming messages, editable replies prepared for approval, and follow-ups that should not be lost.

## How we work

We start from tasks we actually have. We use existing vendor and open-source tools where they fit, then build the connections or behavior the task still needs.

Our experiments include local and cloud environments, task history, tool permissions, and recovery when a workflow stops or its outcome is uncertain. Working in our own setup is one step; a public release needs documented setup and verification outside it.

## Public releases

We plan to release the parts that hold up in our own use as free, open-source tools. Each released component will need its own license, setup instructions and known limitations.

The full application is not available as an installer or hosted service. The public website and documentation describe the work; they are not a demonstration of connected application features.
