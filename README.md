# KBP AI — Knowledge Becomes Progress

**KBP AI is an independent project exploring how people can build working systems around recurring tasks with AI.**

**Private prototype · One founder testing it · No public installer yet**

The [KBP AI organization profile](https://github.com/WestCoastKBP) is our public entry point.

## About this repository

This repository contains product presentation, documentation and brand assets. **It does not contain the product implementation or an installer.** The organization profile is rendered from [profile/README.md](profile/README.md). A public code release will need its own reviewed source, licence and working starting path.
