# Feedback and contributions

This repository maintains KBP AI's public presentation. Product implementation and installation are not published here yet.

Read the [shared philosophy](docs/BRAND.md) before proposing or reviewing a change. Employees, contributors and AI coordinators use the same north star: useful actions and checked results in the outside world, with human control. Security, privacy and recovery are baseline requirements. Apply this standard within the existing permissions and review workflow.

Use [issues](https://github.com/WestCoastKBP/.github/issues) to share:

- A concrete task you would like the product to help with.
- An integration suggestion and the result it should enable.
- A documentation error or broken link.
- A potential collaboration, without confidential details.

For a documentation correction, describe the affected page and the proposed wording. Keep claims consistent with the [current status](docs/STATUS.md).

Do not post credentials, private messages, customer records or other sensitive data. Public issues are a discussion route, not a private support channel or a promised response-time service.
